# Measurements Tool
The Measurements tool is an organizer for measurements saved by the Sweep and Real Time tool.  Use it to view, compare, export and delete measurements.

![Measurements tool](/assets/img/measurements_tool.png "Measurements tool")
{: .app-portrait-right }


## View Measurement
Tap a measurement to display.  The plot has controls similar to the [Sweep](sweep_tool.md) tool.

## Selection
Tap "Select" to choose measurements.

## Delete
Tap <img src="/assets/img/trash.png" alt="Delete" class="app-icon"> to delete selected measurements.

## Compare
Select up to 5 measurements and tap <img src="/assets/img/compare.png" alt="Compare" class="app-icon"> to compare them on the same plot.

The compare plot has controls similar to the [Sweep](sweep_tool.md) tool.  Tap <img src="/assets/img/prevplot.png" alt="Previous Plot" class="app-icon"> and <img src="/assets/img/nextplot.png" alt="Next Plot" class="app-icon"> to choose which measurement is focused.  The cursor and automatic curve fit will follow the focused measurement.  Use a manual curve fit to stop the target curve from shifting.

## Export
Tap <img src="/assets/img/export.png" alt="Export" class="app-icon"> to export selected measurements as [impulse responses](file_formats.md#measurements).

Note - this feature is only available with a [Tuning Bundle](../DOWNLOAD.md#tuning-bundle) purchase.
